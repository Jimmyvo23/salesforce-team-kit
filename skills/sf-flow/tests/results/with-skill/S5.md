**How versions work.** Saving an active flow in Flow Builder creates a new, inactive version. Only one version is active at a time. Activating the new one deactivates the old one, and the old version stays for rollback. Interviews that are already running or paused finish on the version they started on. A deploy also creates a new version, and its `<status>` decides whether it goes live. `<status>Active</status>` activates it on deploy, before any testing. If you deploy from a file, set `<status>Draft</status>` first.
