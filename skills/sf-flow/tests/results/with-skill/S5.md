## How versions work
- Saving a change to an active flow in Flow Builder creates a new version, and that version is inactive.
- Only one version is active at a time. Activating the new one deactivates the old one.
- Interviews that are running or paused finish on the version they started on.
- The old version stays in the flow's version list, so you can roll back by activating it again.
- If you deployed the change instead, the file's `<status>` decides what happens. `Active` replaces the current version on deploy, before any testing. `Draft` leaves the new version inactive.

You can also open **Setup > Flow Trigger Explorer** for Lead. The results matter in two ways:
- Another Lead flow or an Apex trigger that also sets the owner would conflict with this one.
- An active Process Builder process or Workflow Rule that assigns owners would run alongside it, so you'd deactivate that at the same time.
