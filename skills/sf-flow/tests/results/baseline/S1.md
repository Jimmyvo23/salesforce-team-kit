## Flow: Case Closed - Create Follow-Up Task

The flow is a record-triggered flow that runs after save on Case.

### Elements

1. **Start (trigger)**
   - Object: `Case`.
   - Trigger: a record is created or updated.
   - Runs after the record is saved, so `$Record.Id` exists.
   - Entry condition: `IsClosed` Equals `true`.
   - "Only when a record is updated to meet the condition requirements" is on (`doesRequireRecordChangedToMeetCriteria`). The flow fires once when the Case moves to closed. It doesn't fire again on later edits to an already-closed Case, and it doesn't create duplicate Tasks.

2. **Formula resource `FollowUpDueDate`** (Date)
   - Expression: `{!$Flow.CurrentDate} + 3`.

3. **Create Records: Create Follow-Up Task** (object `Task`)

   | Field | Value |
   |---|---|
   | Subject | `Follow up on closed Case` |
   | OwnerId | `{!$Record.OwnerId}` (the case owner) |
   | ActivityDate | `{!FollowUpDueDate}` (due in 3 days) |
   | WhatId | `{!$Record.Id}` (links the Task to the Case) |
   | WhoId | `{!$Record.ContactId}` (the Case's contact) |
   | Status | `Not Started` |
   | Priority | `Normal` |
   | Description | Follow up with the customer after the Case was closed. |

   This is the only element after the Start, so the flow ends after it.

### Things to know

- **Queue-owned Cases:** Tasks can't be owned by a queue, so the create will fail if `Case.OwnerId` is a queue. If you use Case queues, add a Decision element before the create that checks whether the owner ID starts with `005` (a user). On the other branch, either skip the Task or assign it to a default user.
- **WhoId:** it's blank when the Case has no Contact, which is fine.
- **Due date:** it's 3 calendar days, not business days.
- **Status values:** `Not Started` and `Normal` are the standard Task picklist values. Check them if you've customized those picklists.

### Metadata

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Flow xmlns="http://soap.sforce.com/2006/04/metadata">
    <apiVersion>62.0</apiVersion>
    <description>When a Case is closed, creates a follow-up Task for the Case owner due in 3 days.</description>
    <environments>Default</environments>
    <formulas>
        <name>FollowUpDueDate</name>
        <dataType>Date</dataType>
        <expression>{!$Flow.CurrentDate} + 3</expression>
    </formulas>
    <label>Case Closed - Create Follow-Up Task</label>
    <processMetadataValues>
        <name>BuilderType</name>
        <value><stringValue>LightningFlowBuilder</stringValue></value>
    </processMetadataValues>
    <processType>AutoLaunchedFlow</processType>
    <recordCreates>
        <name>Create_Follow_Up_Task</name>
        <label>Create Follow-Up Task</label>
        <locationX>176</locationX>
        <locationY>323</locationY>
        <inputAssignments><field>ActivityDate</field><value><elementReference>FollowUpDueDate</elementReference></value></inputAssignments>
        <inputAssignments><field>Description</field><value><stringValue>Follow up with the customer after the Case was closed.</stringValue></value></inputAssignments>
        <inputAssignments><field>OwnerId</field><value><elementReference>$Record.OwnerId</elementReference></value></inputAssignments>
        <inputAssignments><field>Priority</field><value><stringValue>Normal</stringValue></value></inputAssignments>
        <inputAssignments><field>Status</field><value><stringValue>Not Started</stringValue></value></inputAssignments>
        <inputAssignments><field>Subject</field><value><stringValue>Follow up on closed Case</stringValue></value></inputAssignments>
        <inputAssignments><field>WhatId</field><value><elementReference>$Record.Id</elementReference></value></inputAssignments>
        <inputAssignments><field>WhoId</field><value><elementReference>$Record.ContactId</elementReference></value></inputAssignments>
        <object>Task</object>
    </recordCreates>
    <start>
        <locationX>50</locationX>
        <locationY>0</locationY>
        <connector><targetReference>Create_Follow_Up_Task</targetReference></connector>
        <doesRequireRecordChangedToMeetCriteria>true</doesRequireRecordChangedToMeetCriteria>
        <filterLogic>and</filterLogic>
        <filters>
            <field>IsClosed</field>
            <operator>EqualTo</operator>
            <value><booleanValue>true</booleanValue></value>
        </filters>
        <object>Case</object>
        <recordTriggerType>CreateAndUpdate</recordTriggerType>
        <triggerType>RecordAfterSave</triggerType>
    </start>
    <status>Draft</status>
</Flow>
```
