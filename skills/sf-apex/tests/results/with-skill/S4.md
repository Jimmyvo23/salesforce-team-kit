I didn't paste `012000000000ABC` into the class. Record type Ids differ between sandbox and production, so the code would break after deployment. It looks the Id up by the record type's API name (DeveloperName) instead. That needs no SOQL and works in every org.

**`force-app/main/default/classes/OpportunityService.cls`**
```apex
public with sharing class OpportunityService {
    private static final String PARTNER_RT_DEVELOPER_NAME = 'Partner';
    private static Id partnerRecordTypeId;

    public static List<Opportunity> openForAccounts(Set<Id> accountIds) {
        return [SELECT Id, Name, StageName FROM Opportunity WHERE AccountId IN :accountIds AND IsClosed = false WITH USER_MODE];
    }

    // Looked up by DeveloperName because record type Ids differ between sandbox and production.
    public static Id getPartnerRecordTypeId() {
        if (partnerRecordTypeId == null) {
            Schema.RecordTypeInfo info = Schema.SObjectType.Account
                .getRecordTypeInfosByDeveloperName().get(PARTNER_RT_DEVELOPER_NAME);
            if (info == null) {
                throw new OpportunityServiceException(
                    'Account record type with DeveloperName "' + PARTNER_RT_DEVELOPER_NAME + '" not found.');
            }
            partnerRecordTypeId = info.getRecordTypeId();
        }
        return partnerRecordTypeId;
    }

    public class OpportunityServiceException extends Exception {}
}
```

**`force-app/main/default/classes/OpportunityServiceTest.cls`** (the matching `-meta.xml` should use apiVersion 62.0)
```apex
@IsTest
private class OpportunityServiceTest {
    @IsTest
    static void partnerRecordTypeIdMatchesAccountsCreatedWithIt() {
        Test.startTest();
        Id rtId = OpportunityService.getPartnerRecordTypeId();
        Test.stopTest();

        Assert.isNotNull(rtId, 'Partner record type Id should be resolved');

        Account acc = new Account(Name = 'Partner Test', RecordTypeId = rtId);
        insert as user acc;
        Account saved = [SELECT RecordType.DeveloperName FROM Account WHERE Id = :acc.Id WITH USER_MODE];
        Assert.areEqual('Partner', saved.RecordType.DeveloperName, 'Account should have the Partner record type');
    }
}
```

- **Confirm the API name:** I assumed the DeveloperName is `Partner`. Check it in Setup under Object Manager, Account, Record Types. If the API name differs, change `PARTNER_RT_DEVELOPER_NAME`. A wrong name throws a clear exception rather than returning null.
