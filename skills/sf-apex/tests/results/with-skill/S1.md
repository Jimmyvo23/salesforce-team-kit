## `force-app/main/default/triggers/ContactTrigger.trigger`
```apex
trigger ContactTrigger on Contact (after insert, after update) {
    ContactTriggerHandler.afterSave(Trigger.new, Trigger.oldMap);
}
```

## `force-app/main/default/classes/ContactTriggerHandler.cls`
```apex
public with sharing class ContactTriggerHandler {
    public static void afterSave(List<Contact> contacts, Map<Id, Contact> oldMap) {
        Set<Id> accountIds = new Set<Id>();
        for (Contact c : contacts) {
            Boolean changed = oldMap == null || c.Email != oldMap.get(c.Id).Email;
            if (changed && c.AccountId != null) {
                accountIds.add(c.AccountId);
            }
        }
        if (accountIds.isEmpty()) {
            return;
        }

        Date today = Date.today();
        List<Account> toUpdate = new List<Account>();
        for (Account a : [SELECT Id, Last_Contact_Date__c FROM Account
                          WHERE Id IN :accountIds WITH USER_MODE]) {
            if (a.Last_Contact_Date__c != today) {   // skip no-op updates
                a.Last_Contact_Date__c = today;
                toUpdate.add(a);
            }
        }
        update as user toUpdate;
    }
}
```

## `force-app/main/default/classes/TestDataFactory.cls`
```apex
@IsTest
public class TestDataFactory {
    public static List<Account> accounts(Integer n, Boolean doInsert) {
        List<Account> rows = new List<Account>();
        for (Integer i = 0; i < n; i++) {
            rows.add(new Account(Name = 'Test Account ' + i));
        }
        if (doInsert) {
            insert rows;
        }
        return rows;
    }

    public static List<Contact> contacts(List<Account> parents, Integer perAccount, Boolean doInsert) {
        List<Contact> rows = new List<Contact>();
        for (Account a : parents) {
            for (Integer i = 0; i < perAccount; i++) {
                rows.add(new Contact(LastName = 'Test ' + i, AccountId = a.Id,
                                     Email = 'c' + i + '.' + a.Id + '@example.com'));
            }
        }
        if (doInsert) {
            insert rows;
        }
        return rows;
    }
}
```

## `force-app/main/default/classes/ContactTriggerHandlerTest.cls`
```apex
@IsTest
private class ContactTriggerHandlerTest {
    @TestSetup
    static void setup() {
        TestDataFactory.accounts(50, true);
    }

    private static void clearDates() {
        List<Account> accts = [SELECT Id FROM Account];
        for (Account a : accts) {
            a.Last_Contact_Date__c = null;
        }
        update accts;
    }

    @IsTest
    static void insertOf200ContactsSetsDateOnEveryAccount() {
        List<Contact> contacts = TestDataFactory.contacts([SELECT Id FROM Account], 4, false);
        Assert.areEqual(200, contacts.size(), 'Test builds 200 contacts');

        Test.startTest();
        insert contacts;
        Test.stopTest();

        Assert.areEqual(50, [SELECT COUNT() FROM Account WHERE Last_Contact_Date__c = :Date.today()],
            'Every Account gets today');
    }

    @IsTest
    static void emailChangeOn200ContactsSetsDate() {
        List<Contact> contacts = TestDataFactory.contacts([SELECT Id FROM Account], 4, true);
        clearDates();
        for (Contact c : contacts) {
            c.Email = 'new.' + c.Email;
        }

        Test.startTest();
        update contacts;
        Test.stopTest();

        Assert.areEqual(50, [SELECT COUNT() FROM Account WHERE Last_Contact_Date__c = :Date.today()],
            'All 50 Accounts updated');
    }

    @IsTest
    static void nonEmailChangeLeavesDateAlone() {
        List<Contact> contacts = TestDataFactory.contacts([SELECT Id FROM Account], 1, true);
        clearDates();
        for (Contact c : contacts) {
            c.FirstName = 'Changed';
        }

        Test.startTest();
        update contacts;
        Test.stopTest();

        Assert.areEqual(0, [SELECT COUNT() FROM Account WHERE Last_Contact_Date__c != null],
            'A non-Email change must not set the date');
    }

    @IsTest
    static void contactWithoutAccountIsIgnored() {
        Test.startTest();
        insert new Contact(LastName = 'Orphan', Email = 'orphan@example.com');
        Test.stopTest();

        Assert.areEqual(0, [SELECT COUNT() FROM Account WHERE Last_Contact_Date__c != null],
            'No Account is touched');
    }

    @IsTest
    static void accountAlreadySetToTodayStaysToday() {
        List<Contact> contacts = TestDataFactory.contacts([SELECT Id FROM Account], 1, true);
        for (Contact c : contacts) {
            c.Email = 'again.' + c.Email;
        }

        Test.startTest();
        update contacts;
        Test.stopTest();

        Assert.areEqual(50, [SELECT COUNT() FROM Account WHERE Last_Contact_Date__c = :Date.today()],
            'Date is still today after a second email change');
    }
}
```

## Things to know
- **Not run:** I haven't compiled or run any of this. Run the tests in your sandbox.
- **Prerequisite:** the code assumes `Account.Last_Contact_Date__c` exists as a Date field.
- **Access:** the handler is `with sharing`, and the query and update run in user mode. If the user saving a Contact can't edit the parent Account, or can't edit `Last_Contact_Date__c`, the whole Contact save fails.
- **Decision for you:** should the date be maintained for every user?
  - If only the field or object permission is missing, I can change the update to `update as system`.
  - If users may also lack record access, I can move the query and update into a small `without sharing` inner class.
  - I held back from either because it widens access, so it's your call.
- **Side effects:** updating the Account fires its own triggers, flows and validation rules.
- **Test gap:** the tests run as the admin, so they don't prove the access checks. A `System.runAs` test needs a permission set name from your org. Send it over and I'll add one.
- **Contact without an Account:** a Contact with no Account is skipped.
- **Date:** `Date.today()` uses the running user's time zone.
