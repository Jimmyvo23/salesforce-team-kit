Put each file under `force-app/main/default/`. I read `sourceApiVersion` from `sfdx-project.json`, so every `-meta.xml` uses `62.0`.

**`triggers/ContactTrigger.trigger`**
```apex
trigger ContactTrigger on Contact (after insert, after update) {
    ContactTriggerHandler.afterSave(Trigger.new, Trigger.oldMap);
}
```

**`classes/ContactTriggerHandler.cls`**
```apex
public with sharing class ContactTriggerHandler {
    public static void afterSave(List<Contact> contacts, Map<Id, Contact> oldMap) {
        Set<Id> accountIds = new Set<Id>();
        for (Contact c : contacts) {
            Boolean emailChanged = oldMap == null || c.Email != oldMap.get(c.Id).Email;
            if (emailChanged && c.AccountId != null) {
                accountIds.add(c.AccountId);
            }
        }
        if (accountIds.isEmpty()) {
            return;
        }

        Date today = Date.today();
        List<Account> toUpdate = new List<Account>();
        for (Account a : [SELECT Id, Last_Contact_Date__c FROM Account
                          WHERE Id IN :accountIds WITH USER_MODE]) {
            if (a.Last_Contact_Date__c != today) {
                a.Last_Contact_Date__c = today;
                toUpdate.add(a);
            }
        }
        update as user toUpdate;
    }
}
```

**`classes/TestDataFactory.cls`**
```apex
@IsTest
public class TestDataFactory {
    public static List<Account> accounts(Integer n, Boolean doInsert) {
        List<Account> rows = new List<Account>();
        for (Integer i = 0; i < n; i++) {
            rows.add(new Account(Name = 'Test Account ' + i));
        }
        if (doInsert) {
            insert rows;
        }
        return rows;
    }

    public static List<Contact> contacts(List<Account> parents, Integer perAccount, Boolean doInsert) {
        List<Contact> rows = new List<Contact>();
        for (Account a : parents) {
            for (Integer i = 0; i < perAccount; i++) {
                rows.add(new Contact(LastName = 'Test ' + i, AccountId = a.Id,
                                     Email = 'c' + i + '.' + a.Id + '@example.com'));
            }
        }
        if (doInsert) {
            insert rows;
        }
        return rows;
    }
}
```

**`classes/ContactTriggerHandlerTest.cls`**
```apex
@IsTest
private class ContactTriggerHandlerTest {
    @TestSetup
    static void setup() {
        TestDataFactory.accounts(50, true);
    }

    private static void clearDates() {
        List<Account> accts = [SELECT Id FROM Account];
        for (Account a : accts) {
            a.Last_Contact_Date__c = null;
        }
        update accts;
    }

    @IsTest
    static void insertOf200ContactsSetsDateOnEveryAccount() {
        List<Account> accts = [SELECT Id FROM Account];
        List<Contact> contacts = TestDataFactory.contacts(accts, 4, false);

        Test.startTest();
        insert contacts;
        Test.stopTest();

        Assert.areEqual(200, contacts.size(), 'Bulk test uses 200 contacts');
        for (Account a : [SELECT Last_Contact_Date__c FROM Account]) {
            Assert.areEqual(Date.today(), a.Last_Contact_Date__c, 'Every Account gets today');
        }
    }

    @IsTest
    static void emailChangeOn200ContactsSetsDate() {
        List<Contact> contacts = TestDataFactory.contacts([SELECT Id FROM Account], 4, true);
        clearDates();
        for (Contact c : contacts) {
            c.Email = 'new.' + c.Email;
        }

        Test.startTest();
        update contacts;
        Test.stopTest();

        Assert.areEqual(50, [SELECT COUNT() FROM Account WHERE Last_Contact_Date__c = :Date.today()],
            'All 50 Accounts updated');
    }

    @IsTest
    static void nonEmailChangeLeavesDateAlone() {
        List<Contact> contacts = TestDataFactory.contacts([SELECT Id FROM Account], 1, true);
        clearDates();
        for (Contact c : contacts) {
            c.FirstName = 'Changed';
        }

        Test.startTest();
        update contacts;
        Test.stopTest();

        Assert.areEqual(0, [SELECT COUNT() FROM Account WHERE Last_Contact_Date__c != null],
            'A non-Email change must not set the date');
    }

    @IsTest
    static void contactWithoutAccountIsIgnored() {
        Contact c = new Contact(LastName = 'Orphan', Email = 'orphan@example.com');

        Test.startTest();
        insert c;
        Test.stopTest();

        Assert.isNotNull(c.Id, 'Contact saved without error');
        Assert.areEqual(0, [SELECT COUNT() FROM Account WHERE Last_Contact_Date__c != null],
            'No Account is touched');
    }

    @IsTest
    static void dateAlreadyTodayStaysToday() {
        List<Contact> contacts = TestDataFactory.contacts([SELECT Id FROM Account], 1, true);
        for (Contact c : contacts) {
            c.Email = 'again.' + c.Email;
        }

        Test.startTest();
        update contacts;
        Test.stopTest();

        Assert.areEqual(50, [SELECT COUNT() FROM Account WHERE Last_Contact_Date__c = :Date.today()],
            'Dates remain today');
    }
}
```

**Meta files.** `ContactTrigger.trigger-meta.xml` uses the root element `ApexTrigger`. The three class files (`ContactTriggerHandler`, `TestDataFactory`, `ContactTriggerHandlerTest`) each need a `.cls-meta.xml` with the root element `ApexClass`. All four contain the same two settings:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<ApexTrigger xmlns="http://soap.sforce.com/2006/04/metadata">
    <apiVersion>62.0</apiVersion>
    <status>Active</status>
</ApexTrigger>
```

**How it works**
- **One trigger per object:** `ContactTrigger` holds no logic and calls the handler. No Contact trigger exists in the project yet. If one already exists in your org, call the handler from it instead of adding a second trigger.
- **Which Contacts count:** Every inserted Contact counts. On update, only Contacts whose Email changed count. Contacts with no Account are skipped.
- **Query and DML:** The handler runs one query (`WITH USER_MODE`) and one `update as user`. It skips Accounts that already have today's date, which avoids pointless updates.
- **Bulk handling:** The tests cover 200 Contacts on insert and on update. They also cover a non-Email change, a Contact with no Account, and an Account whose date is already today.
- **`TestDataFactory`:** It didn't exist in the project, so I added it.

**Decision for you:** `update as user` runs with the saving user's permissions. If that user can't edit the Account, or can't edit `Last_Contact_Date__c`, the whole Contact save fails. Should the date be kept current for every user regardless of their access? If so, change that one line to `update as system toUpdate;` and add a comment giving the reason. I left it in user mode because that is the safer default.

**Not covered:** There is no `System.runAs` test for a user without Account access. It needs a permission set from your org that I don't know about. Tell me its name and I'll add the test.

**Other things to check**
- `Date.today()` uses the running user's time zone.
- Updating the Account fires its own triggers, flows and validation rules.
- Deploy and run the tests in your sandbox first. A person on your side should handle any production deployment.
