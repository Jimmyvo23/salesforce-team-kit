**`force-app/main/default/classes/CaseService.cls`**
```apex
public with sharing class CaseService {
    @AuraEnabled(cacheable=true)
    public static List<Case> openForAccount(Id accountId) {
        return [SELECT Id, CaseNumber, Subject, Status, Priority, CreatedDate FROM Case WHERE AccountId = :accountId AND IsClosed = false WITH USER_MODE ORDER BY CreatedDate DESC LIMIT 50];
    }
}
```

**`force-app/main/default/lwc/accountOpenCases/accountOpenCases.js`**
```js
import { LightningElement, api, wire } from 'lwc';
import openForAccount from '@salesforce/apex/CaseService.openForAccount';

const COLUMNS = [
    { label: 'Case', fieldName: 'caseUrl', type: 'url', typeAttributes: { label: { fieldName: 'CaseNumber' }, target: '_self' } },
    { label: 'Subject', fieldName: 'Subject' },
    { label: 'Status', fieldName: 'Status' },
    { label: 'Priority', fieldName: 'Priority' },
    { label: 'Created', fieldName: 'CreatedDate', type: 'date' }
];

export default class AccountOpenCases extends LightningElement {
    @api recordId;
    columns = COLUMNS;
    cases = [];
    error;

    @wire(openForAccount, { accountId: '$recordId' })
    wiredCases({ data, error }) {
        if (data) {
            this.cases = data.map((c) => ({ ...c, caseUrl: `/lightning/r/Case/${c.Id}/view` }));
            this.error = undefined;
        } else if (error) {
            this.cases = [];
            this.error = error?.body?.message || 'Unable to load cases.';
        }
    }

    get hasCases() {
        return this.cases.length > 0;
    }

    get title() {
        return `Open Cases (${this.cases.length})`;
    }
}
```

**`force-app/main/default/lwc/accountOpenCases/accountOpenCases.html`**
```html
<template>
    <lightning-card title={title} icon-name="standard:case">

            <template lwc:elseif={hasCases}>
                <lightning-datatable key-field="Id" data={cases} columns={columns} hide-checkbox-column></lightning-datatable>

</template>
```

- **Query:** it returns open Cases (`IsClosed = false`) for the account, newest first, capped at 50. Because of `USER_MODE`, it respects the running user's object and field permissions.
- **Component:** it shows a datatable with the case number as a link, plus subject, status, priority and created date. It also handles the empty and error states.
