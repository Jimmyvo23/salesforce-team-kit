# S4: Guest user (baseline)

The project has no Experience Cloud site metadata, so I haven't changed anything. There's no site, guest profile, or Product2 config in the repo, and the only org alias is the `uat` sandbox. I need two answers before I can write the config.

1. **What is the site's name?** Salesforce names the guest user profile `<Site Name> Profile`, and the guest sharing rule and the profile's object permission both attach to it.
2. **Which products should guests see?** Guest users get no access by default, so I'd configure it like this:
   - **Object permission:** Read-only on Product2, with no create, edit, or delete. It goes on the site's guest profile, not a permission set, because guest users can't be assigned permission sets in the usual way.
   - **Field access:** Read on only the fields the catalogue page shows, such as Name, ProductCode, Description, and Family. Internal fields stay hidden.
   - **Record access:** A guest user sharing rule on Product2. Product2 is public read/write by default, so it may not be needed. If the org-wide default is Private, I'd scope the rule with criteria such as `IsActive = true` and a "Show on portal" flag, not share every record.
   - **Pricing:** If the catalogue shows prices, guests also need access to the PricebookEntry and Pricebook2 records, and that exposes your pricing. I'd want you to confirm that first.

I'll build this as metadata in `force-app` and deploy it only to `uat`. Production is yours to deploy with a change set. Send me the site name and which fields and products to expose, and I'll write it.
