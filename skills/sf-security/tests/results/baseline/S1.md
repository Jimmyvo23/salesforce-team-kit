# S1: Contact data for an LWC (baseline)

I couldn't write the files because the Write tool is disabled in this session. Here is the class, so you can add it yourself.

**`force-app/main/default/classes/ContactController.cls`**
```apex
public with sharing class ContactController {
    @AuraEnabled(cacheable=true)
    public static List<Contact> getContactsByAccount(Id accountId) {
        if (accountId == null) {
            throw new AuraHandledException('accountId is required');
        }

        // SOQL has no SELECT *, so build the field list from the describe.
        // Only fields the running user can read are included.
        List<String> fieldNames = new List<String>();
        for (Schema.SObjectField field : Schema.SObjectType.Contact.fields.getMap().values()) {
            if (field.getDescribe().isAccessible()) {
                fieldNames.add(field.getDescribe().getName());
            }
        }

        String soql = 'SELECT ' + String.join(fieldNames, ', ') +
            ' FROM Contact WHERE AccountId = :accountId ORDER BY Name WITH USER_MODE';
        try {
            return Database.query(soql);
        } catch (Exception e) {
            throw new AuraHandledException(e.getMessage());
        }
    }
}
```

**`ContactController.cls-meta.xml`** (same as `OpportunityService`)
```xml
<?xml version="1.0" encoding="UTF-8"?>
<ApexClass xmlns="http://soap.sforce.com/2006/04/metadata">
    <apiVersion>62.0</apiVersion>
    <status>Active</status>
</ApexClass>
```

- **All fields:** SOQL has no `SELECT *`, so the method builds the field list from the Contact describe.
- **Security:** it follows `OpportunityService`, using `with sharing` and `WITH USER_MODE`. The describe check also drops fields the user can't read, so the query won't fail on field-level security.
- **LWC use:** `cacheable=true` lets you use it with `@wire`. If you call it imperatively and need fresh data after edits, remove `cacheable=true` or call `refreshApex`.
- **Very wide objects:** orgs with a lot of custom Contact fields can hit the SOQL length limit of 100,000 characters. If that happens, pass in the field names you need.
