## Guest safety

1. **Don't give guests Edit** (or Delete, View All, Modify All) on Product2, even if asked later. Read is the most a guest gets here.
2. **Don't use `without sharing` Apex or system-mode queries to show guests more.** Any Apex the site calls should be `with sharing` and `WITH USER_MODE`.
3. **Records guests create are owned by the site's default internal owner** (site Preferences, secure guest user settings). This setup creates no records, but if you add a form later, check that an active internal user is set. Also route those records to different users or queues with assignment rules or automation, so one person doesn't own everything.
