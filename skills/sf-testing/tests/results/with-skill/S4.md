## Assumptions

I couldn't find `ErpService` in the project (no `**/classes/*.cls` match, no Named Credential metadata), and I have no shell here to retrieve it from `uat`. I wrote the test against this assumed signature:

- `ErpService.sendOrder(Id orderId)` POSTs the order as JSON to `callout:ERP/orders`.
- It returns the ERP id from the response body (`{"id":"..."}`) on 2xx.
- It throws `ErpService.ErpException` with the status code in the message on any other status.
- The record it sends is an `Order`.

If any of that is wrong, change the class and method names, the endpoint, the exception type, and the factory record. Retrieve the real class with `sf project retrieve start -m ApexClass:ErpService -o uat` to check. `sourceApiVersion` is 62.0, so the `-meta.xml` files use that.

## Test plan

| Test | Given | When | Then |
|---|---|---|---|
| `successReturnsErpId` | ERP replies 201 `{"id":"ERP-42"}` | `sendOrder` | Returns `ERP-42`. Request was one POST to `callout:ERP/orders` with the order Id in the body. |
| `clientErrorThrowsWithStatus` | ERP replies 400 | `sendOrder` | `ErpException`, message contains `400`. |

## Files

`force-app/main/default/classes/ErpServiceTest.cls`
```apex
@IsTest
private class ErpServiceTest {
    // ASSUMES: ErpService.sendOrder(Id orderId) POSTs JSON to callout:ERP/orders,
    // returns the ERP id on 2xx, throws ErpService.ErpException (message has the status) otherwise.
    private class ErpMock implements HttpCalloutMock {
        private final Integer status;
        private final String body;
        public List<HttpRequest> requests = new List<HttpRequest>();

        ErpMock(Integer status, String body) {
            this.status = status;
            this.body = body;
        }

        public HttpResponse respond(HttpRequest req) {
            requests.add(req);
            HttpResponse res = new HttpResponse();
            res.setStatusCode(status);
            res.setBody(body);
            return res;
        }
    }

    @TestSetup
    static void setup() {
        Account a = TestDataFactory.account('ERP Co', null, null);
        insert a;
        insert TestDataFactory.order(a.Id);
    }

    static Id orderId() {
        return [SELECT Id FROM Order LIMIT 1].Id;
    }

    @IsTest
    static void successReturnsErpId() {
        Id recordId = orderId();
        ErpMock mock = new ErpMock(201, '{"id":"ERP-42"}');

        Test.startTest();
        Test.setMock(HttpCalloutMock.class, mock);
        String erpId = ErpService.sendOrder(recordId);
        Test.stopTest();

        Assert.areEqual('ERP-42', erpId, 'Returns the id from the ERP response');
        Assert.areEqual(1, mock.requests.size(), 'Exactly one callout');
        HttpRequest req = mock.requests[0];
        Assert.areEqual('POST', req.getMethod(), 'Uses POST');
        Assert.isTrue(req.getEndpoint().startsWith('callout:ERP/orders'), 'Uses the Named Credential');
        Assert.isTrue(req.getBody().contains(String.valueOf(recordId)), 'Body carries the order Id');
    }

    @IsTest
    static void clientErrorThrowsWithStatus() {
        Id recordId = orderId();

        Test.startTest();
        Test.setMock(HttpCalloutMock.class, new ErpMock(400, '{"error":"bad request"}'));
        try {
            ErpService.sendOrder(recordId);
            Assert.fail('Expected ErpService.ErpException for a 400');
        } catch (ErpService.ErpException e) {
            Assert.isTrue(e.getMessage().contains('400'), 'The error names the status');
        }
        Test.stopTest();
    }

    @IsTest
    static void serverErrorThrowsWithStatus() {
        Id recordId = orderId();

        Test.startTest();
        Test.setMock(HttpCalloutMock.class, new ErpMock(500, '{"error":"down"}'));
        try {
            ErpService.sendOrder(recordId);
            Assert.fail('Expected ErpService.ErpException for a 500');
        } catch (ErpService.ErpException e) {
            Assert.isTrue(e.getMessage().contains('500'), 'The error names the status');
        }
        Test.stopTest();
    }
}
```
