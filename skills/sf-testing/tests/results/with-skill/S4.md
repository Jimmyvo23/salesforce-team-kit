# S4: Callout test (with-skill)

`ErpService` isn't in the project. `force-app` only has `OpportunityService.cls`, and I have no shell here to retrieve it from the sandbox. So I wrote the test against an assumed signature. Nothing has been saved or run.

## Assumptions (adjust if wrong)
- `ErpService.sendOrder(Id orderId)` POSTs JSON to `callout:ERP/orders`. `ERP` is the Named Credential name.
- It returns the ERP id from the response body (`{"id":"ERP-42"}`) on a 2xx.
- It throws `ErpService.ErpException` on any other status, and the message contains the status code.
- The record it sends is an `Order`.
- If your signature, endpoint, exception type or failure behaviour differs, change only the `ErpService.sendOrder(...)` calls, the endpoint assert and the `catch` type. If it returns null or stores the error on the record instead of throwing, assert that instead.
- I named the factory `ErpTestDataFactory`. A `TestDataFactory` may already exist in the sandbox, and this name avoids overwriting it.

## Test plan

| Test | Given | When | Then |
|---|---|---|---|
| `createdResponseReturnsErpId` | Order exists, mock returns 201 `{"id":"ERP-42"}` | `sendOrder` | Returns `ERP-42`. The request was a POST to `callout:ERP/orders` with a non-blank body containing the order Id. |
| `okResponseReturnsErpId` | Mock returns 200 | `sendOrder` | Returns the id (2xx boundary). |
| `serverErrorThrowsErpException` | Mock returns 500 | `sendOrder` | Throws `ErpException` naming `500`. |
| `clientErrorThrowsErpException` | Mock returns 400 | `sendOrder` | Throws `ErpException` naming `400`. |

Bulk and restricted-user tests don't apply, because the method makes one callout per order.

`force-app/main/default/classes/ErpServiceTest.cls`
```apex
@IsTest
private class ErpServiceTest {
    // ASSUMES: ErpService.sendOrder(Id orderId) POSTs JSON to callout:ERP/orders,
    // returns the ERP id on 2xx and throws ErpService.ErpException on other statuses.
    private class ErpMock implements HttpCalloutMock {
        public HttpRequest captured;
        private final Integer status;
        private final String body;

        ErpMock(Integer status, String body) {
            this.status = status;
            this.body = body;
        }

        public HttpResponse respond(HttpRequest req) {
            captured = req;
            HttpResponse res = new HttpResponse();
            res.setStatusCode(status);
            res.setBody(body);
            return res;
        }
    }

    @TestSetup
    static void setup() {
        ErpTestDataFactory.createOrder();
    }

    @IsTest
    static void createdResponseReturnsErpId() {
        Id orderId = [SELECT Id FROM Order LIMIT 1].Id;
        ErpMock mock = new ErpMock(201, '{"id":"ERP-42"}');

        Test.startTest();
        Test.setMock(HttpCalloutMock.class, mock);
        String erpId = ErpService.sendOrder(orderId);
        Test.stopTest();

        Assert.areEqual('ERP-42', erpId, 'Returns the id from the ERP response');
        Assert.isNotNull(mock.captured, 'A callout was made');
        Assert.areEqual('POST', mock.captured.getMethod(), 'Uses POST');
        Assert.isTrue(mock.captured.getEndpoint().startsWith('callout:ERP/orders'), 'Uses the ERP Named Credential');
        Assert.isFalse(String.isBlank(mock.captured.getBody()), 'Sends a JSON body');
        Assert.isTrue(mock.captured.getBody().contains(String.valueOf(orderId)), 'Body carries the order id');
    }

    @IsTest
    static void okResponseReturnsErpId() {
        Id orderId = [SELECT Id FROM Order LIMIT 1].Id;

        Test.startTest();
        Test.setMock(HttpCalloutMock.class, new ErpMock(200, '{"id":"ERP-7"}'));
        String erpId = ErpService.sendOrder(orderId);
        Test.stopTest();

        Assert.areEqual('ERP-7', erpId, 'A 200 is treated as success');
    }

    @IsTest
    static void serverErrorThrowsErpException() {
        Id orderId = [SELECT Id FROM Order LIMIT 1].Id;
        Boolean thrown = false;

        Test.startTest();
        Test.setMock(HttpCalloutMock.class, new ErpMock(500, '{"error":"down"}'));
        try {
            ErpService.sendOrder(orderId);
        } catch (ErpService.ErpException e) {
            thrown = true;
            Assert.isTrue(e.getMessage().contains('500'), 'The error names the status');
        }
        Test.stopTest();

        Assert.isTrue(thrown, 'Expected ErpService.ErpException for a 500');
    }

    @IsTest
    static void clientErrorThrowsErpException() {
        Id orderId = [SELECT Id FROM Order LIMIT 1].Id;
        Boolean thrown = false;

        Test.startTest();
        Test.setMock(HttpCalloutMock.class, new ErpMock(400, '{"error":"bad request"}'));
        try {
            ErpService.sendOrder(orderId);
        } catch (ErpService.ErpException e) {
            thrown = true;
            Assert.isTrue(e.getMessage().contains('400'), 'The error names the status');
        }
        Test.stopTest();

        Assert.isTrue(thrown, 'Expected ErpService.ErpException for a 400');
    }
}
```
