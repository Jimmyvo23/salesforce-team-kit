# S1: Tests from a story (with-skill)

I couldn't write files in this session, so every file is below with its path. The project has no flow for T-012: there is no `*.flow-meta.xml`, only the `Partner_Discount__c` field. The tests are written against the story and need the flow active in `uat` before they can pass.

## Assumptions
- **Flow:** it's a record-triggered flow on Opportunity, so it runs in system context. I assert that a user who can't edit `Partner_Discount__c` still gets the 10.
- **Picklist values:** Account Type has `Partner` and `Customer`. Opportunity Type has `Renewal` and `New Customer`. Change them in `TestDataFactory` if your org differs.
- **Factory:** `TestDataFactory` doesn't exist in the project. If it already exists in `uat`, retrieve it with `sf project retrieve start -m ApexClass:TestDataFactory -o uat` and add the two methods instead of replacing it.
- **API version:** `sourceApiVersion` is 62.0, so DML defaults to system mode. The restricted user's insert uses `insert as user` explicitly.
- **Percent field:** `Partner_Discount__c` is a Percent field, so 10 means 10%.

## Test plan

| Test method | Given | When | Then |
|---|---|---|---|
| `partnerRenewalGetsTenPercentDiscount` (AC1) | Partner Account | Renewal Opp inserted | `Partner_Discount__c` = 10 |
| `customerRenewalLeavesDiscountBlank` (AC2) | Customer Account | Renewal Opp inserted | `Partner_Discount__c` is null |
| `partnerNonRenewalLeavesDiscountBlank` (extra negative) | Partner Account | Non-renewal Opp inserted | `Partner_Discount__c` is null |
| `existingDiscountIsNotChangedOnEdit` (AC3) | Renewal Opp on a Customer Account with discount 5, so create doesn't overwrite it | Opp moved to the Partner Account (an edit that would match) | `Partner_Discount__c` is still 5 |
| `bulkInsertOf200PartnerRenewalsAllGetDiscount` (edge) | Partner Account | 200 renewal Opps in one DML | `COUNT()` of Opps with discount 10 is 200, none with other values |
| `userWithoutDiscountEditStillGetsDiscount` (edge) | User with Read-only on `Partner_Discount__c`, owning a Partner Account | User inserts a renewal Opp | Discount is 10 (flow runs in system context) |

```apex
@IsTest
public class TestDataFactory {
    public static Account account(String name, String type, Id ownerId) {
        Account a = new Account(Name = name, Type = type);
        if (ownerId != null) { a.OwnerId = ownerId; }
        return a;                                  // caller inserts, so tests choose when DML happens

    public static List<Opportunity> opportunities(Id accountId, String type, Integer n) {
        List<Opportunity> rows = new List<Opportunity>();
        for (Integer i = 0; i < n; i++) {
            rows.add(new Opportunity(
                Name = 'Test opp ' + i,
                AccountId = accountId,
                Type = type,
                StageName = 'Prospecting',
                CloseDate = Date.today().addDays(30)
            ));
        }
        return rows;
    }
}
```

```apex
@IsTest
public class RestrictedUser {
    /** A Minimum Access user with Read/Create on the object, Edit on editFields, Read-only on readOnlyFields. */
    public static User create(String sobjectName, List<String> editFields, List<String> readOnlyFields) {
        Profile p = [SELECT Id FROM Profile WHERE Name = 'Minimum Access - Salesforce' LIMIT 1];
        String unique = String.valueOf(Crypto.getRandomLong()).remove('-');   // usernames are unique across all orgs
        User u = new User(Alias = 'rtest', LastName = 'Restricted', Email = 'rtest' + unique + '@example.com',
            Username = 'rtest' + unique + '@example.com.test', ProfileId = p.Id,
            EmailEncodingKey = 'UTF-8', LanguageLocaleKey = 'en_US', LocaleSidKey = 'en_US',
            TimeZoneSidKey = 'America/Los_Angeles');
        System.runAs(new User(Id = UserInfo.getUserId())) {
            insert u;
            PermissionSet ps = new PermissionSet(Name = 'Test_Restricted_' + unique.left(10), Label = 'Test restricted');
            insert ps;
            List<SObject> perms = new List<SObject>{
                new ObjectPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    PermissionsRead = true, PermissionsCreate = true, PermissionsEdit = true),
                new ObjectPermissions(ParentId = ps.Id, SobjectType = 'Account', PermissionsRead = true)
            };
            Map<String, Schema.SObjectField> fieldMap =
                Schema.getGlobalDescribe().get(sobjectName).getDescribe().fields.getMap();
            for (String f : editFields) {
                if (!fieldMap.get(f).getDescribe().isPermissionable()) { continue; }   // required, OwnerId, master-detail
                perms.add(new FieldPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    Field = sobjectName + '.' + f, PermissionsRead = true, PermissionsEdit = true));
            }
            for (String f : readOnlyFields) {
                perms.add(new FieldPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    Field = sobjectName + '.' + f, PermissionsRead = true, PermissionsEdit = false));
            }
            insert perms;
            insert new PermissionSetAssignment(AssigneeId = u.Id, PermissionSetId = ps.Id);
        }
        return u;
    }
}
```

`force-app/main/default/classes/PartnerRenewalDiscountTest.cls`
```apex
@IsTest
private class PartnerRenewalDiscountTest {
    @TestSetup
    static void setup() {
        insert new List<Account>{
            TestDataFactory.account('Partner Co', 'Partner', null),
            TestDataFactory.account('Customer Co', 'Customer', null)
        };
    }

    static Id accountId(String name) {
        return [SELECT Id FROM Account WHERE Name = :name LIMIT 1].Id;
    }

    // AC1 (positive)
    @IsTest
    static void partnerRenewalGetsTenPercentDiscount() {
        Opportunity o = TestDataFactory.opportunities(accountId('Partner Co'), 'Renewal', 1)[0];
        Test.startTest();
        insert o;
        Test.stopTest();
        Assert.areEqual(10, [SELECT Partner_Discount__c FROM Opportunity WHERE Id = :o.Id].Partner_Discount__c,
            'Renewal on a Partner Account gets 10');
    }

    // AC2 (negative)
    @IsTest
    static void customerRenewalLeavesDiscountBlank() {
        Opportunity o = TestDataFactory.opportunities(accountId('Customer Co'), 'Renewal', 1)[0];
        Test.startTest();
        insert o;
        Test.stopTest();
        Assert.isNull([SELECT Partner_Discount__c FROM Opportunity WHERE Id = :o.Id].Partner_Discount__c,
            'Renewal on a Customer Account stays blank');
    }

    // Negative: the Opportunity type matters, not only the Account type
    @IsTest
    static void partnerNonRenewalLeavesDiscountBlank() {
        Opportunity o = TestDataFactory.opportunities(accountId('Partner Co'), 'New Customer', 1)[0];
        Test.startTest();
        insert o;
        Test.stopTest();
        Assert.isNull([SELECT Partner_Discount__c FROM Opportunity WHERE Id = :o.Id].Partner_Discount__c,
            'Only renewals get the discount');
    }

    // AC3 (already set): seeded 5 differs from the 10 the flow writes. The seed sits on a Customer
    // Account so the create doesn't match; the edit moves it to the Partner Account, which would match.
    @IsTest
    static void existingDiscountIsNotChangedOnEdit() {
        Opportunity o = TestDataFactory.opportunities(accountId('Customer Co'), 'Renewal', 1)[0];
        o.Partner_Discount__c = 5;
        insert o;
        Opportunity moved = new Opportunity(Id = o.Id, AccountId = accountId('Partner Co'), Name = 'Edited');
        Test.startTest();
        update moved;
        Test.stopTest();
        Assert.areEqual(5, [SELECT Partner_Discount__c FROM Opportunity WHERE Id = :o.Id].Partner_Discount__c,
            'An existing discount survives edits');
    }

    // Edge: 200 in one DML
    @IsTest
    static void bulkInsertOf200PartnerRenewalsAllGetDiscount() {
        Id partnerId = accountId('Partner Co');
        List<Opportunity> rows = TestDataFactory.opportunities(partnerId, 'Renewal', 200);
        Test.startTest();
        insert rows;
        Test.stopTest();
        Assert.areEqual(200, [SELECT COUNT() FROM Opportunity WHERE AccountId = :partnerId AND Partner_Discount__c = 10],
            'All 200 renewals get 10');
        Assert.areEqual(0, [SELECT COUNT() FROM Opportunity WHERE AccountId = :partnerId AND Partner_Discount__c != 10],
            'No renewal has another value');
    }

    // Edge: user without edit access to the field. ASSUMES the flow runs in system context,
    // so it still sets the field. If the story wants the user blocked, change this expectation.
    @IsTest
    static void userWithoutDiscountEditStillGetsDiscount() {
        User u = RestrictedUser.create('Opportunity',
            new List<String>{ 'Name', 'StageName', 'CloseDate', 'AccountId', 'Type' },
            new List<String>{ 'Partner_Discount__c' });
        Account partner = TestDataFactory.account('Partner Owned', 'Partner', u.Id);   // user owns the parent
        insert partner;
        Opportunity o = TestDataFactory.opportunities(partner.Id, 'Renewal', 1)[0];

        System.runAs(u) {
            Assert.isFalse(Schema.SObjectType.Opportunity.fields.Partner_Discount__c.isUpdateable(),
                'Precondition: the user cannot edit Partner_Discount__c');
            Test.startTest();
            insert as user o;
            Test.stopTest();
        }
        // Assert outside runAs, as the test's own user, so the field is readable.
        Assert.areEqual(10, [SELECT Partner_Discount__c FROM Opportunity WHERE Id = :o.Id].Partner_Discount__c,
            'The flow sets the field the user cannot edit');
    }
}
```

## Run

Deploy only the new classes to the sandbox. Don't deploy the whole `force-app` folder.
```sh
sf project deploy start -o uat -m ApexClass:TestDataFactory -m ApexClass:RestrictedUser -m ApexClass:PartnerRenewalDiscountTest
sf apex run test -o uat --class-names PartnerRenewalDiscountTest --code-coverage --result-format json --wait 10 > test-result.json
sf apex run test -o uat --test-level RunLocalTests --result-format json --wait 20 > test-result-all.json
```
In the JSON, read these:
- `result.summary.outcome`, `passing` and `failing`.
- Every `result.tests[]` entry whose `Outcome` isn't `Pass`, with its `Message` and `StackTrace`.
- `result.coverage.coverage[]` for `coveredPercent`. The flow's behaviour is proven by the asserts, not by Apex coverage.

If every test fails with a null discount, the flow isn't active in `uat`. Check `FlowDefinitionView` for it.
