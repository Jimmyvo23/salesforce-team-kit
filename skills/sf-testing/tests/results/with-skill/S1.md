## Assumptions
- **The flow isn't in the project.** There is no `*.flow-meta.xml`, so I wrote the tests against the story. The flow must be active in `uat` when they run.
- **Picklist values.** I assumed `Account.Type` has `Partner` and `Customer`, and `Opportunity.Type` has `Renewal`. If your org uses other values, change them in `TestDataFactory`.
- **Restricted user.** I assumed a record-triggered flow, which runs in system context. The discount is therefore still set (10) for a user who can't edit `Partner_Discount__c`. If the logic is Apex with user-mode DML, this test would need to assert a `DmlException` instead.
- **API version and factory.** `sourceApiVersion` is 62.0, so database operations default to system mode. `TestDataFactory` and `RestrictedUser` don't exist in the project, so I created them. If `TestDataFactory` already exists in `uat`, retrieve it and add `account` and `renewalOpportunities` to it. Don't overwrite it.
- **Test sandbox.** The sandbox alias is `uat`, from `.team/team.json`.

## Test plan

| Test | Given | When | Then |
|---|---|---|---|
| `partnerAccountRenewalGetsTenPercentDiscount` (AC1) | Partner Account | Insert a renewal Opportunity | `Partner_Discount__c` = 10 |
| `customerAccountRenewalDiscountStaysBlank` (AC2) | Customer Account | Insert a renewal | `Partner_Discount__c` is null |
| `existingDiscountIsNotChangedOnEdit` (AC3) | Renewal on the Customer Account, seeded with 5 (differs from 10) | Move it to the Partner Account (an edit that would match) | Still 5 |
| `bulkInsertOf200PartnerRenewalsAllGetDiscount` | Partner Account | Insert 200 renewals in one DML | All 200 exist and all 200 have 10 |
| `userWithoutDiscountEditStillGetsTenPercent` | User with Read-only on `Partner_Discount__c` (precondition asserted) who owns the Partner Account | `insert as user` of a renewal | 10, asserted after `runAs` |

**`TestDataFactory.cls`**
```apex
@IsTest
public class TestDataFactory {
    public static Account account(String name, String type, Id ownerId) {
        Account a = new Account(Name = name, Type = type);
        if (ownerId != null) { a.OwnerId = ownerId; }
        return a;                                  // caller inserts, so tests choose when DML happens
    }

    public static List<Opportunity> renewalOpportunities(Id accountId, Integer n) {
        List<Opportunity> rows = new List<Opportunity>();
        for (Integer i = 0; i < n; i++) {
            rows.add(new Opportunity(
                Name = 'Renewal ' + i,
                AccountId = accountId,
                Type = 'Renewal',
                StageName = 'Prospecting',
                CloseDate = Date.today().addDays(30)
            ));
        }
        return rows;
    }
}
```

**`RestrictedUser.cls`**
```apex
@IsTest
public class RestrictedUser {
    /** A Minimum Access user with Read/Create on the object, Edit on editFields, Read-only on readOnlyFields. */
    public static User create(String sobjectName, List<String> editFields, List<String> readOnlyFields) {
        Profile p = [SELECT Id FROM Profile WHERE Name = 'Minimum Access - Salesforce' LIMIT 1];
        String unique = String.valueOf(Crypto.getRandomLong()).remove('-');   // usernames are unique across all orgs
        User u = new User(Alias = 'rtest', LastName = 'Restricted', Email = 'rtest' + unique + '@example.com',
            Username = 'rtest' + unique + '@example.com.test', ProfileId = p.Id,
            EmailEncodingKey = 'UTF-8', LanguageLocaleKey = 'en_US', LocaleSidKey = 'en_US',
            TimeZoneSidKey = 'America/Los_Angeles');
        System.runAs(new User(Id = UserInfo.getUserId())) {
            insert u;
            PermissionSet ps = new PermissionSet(Name = 'Test_Restricted_' + unique.left(10), Label = 'Test restricted');
            insert ps;
            List<SObject> perms = new List<SObject>{
                new ObjectPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    PermissionsRead = true, PermissionsCreate = true, PermissionsEdit = true),
                new ObjectPermissions(ParentId = ps.Id, SobjectType = 'Account', PermissionsRead = true)
            };
            Map<String, Schema.SObjectField> fieldMap =
                Schema.getGlobalDescribe().get(sobjectName).getDescribe().fields.getMap();
            for (String f : editFields) {
                if (!fieldMap.get(f).getDescribe().isPermissionable()) { continue; }   // e.g. OwnerId, master-detail
                perms.add(new FieldPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    Field = sobjectName + '.' + f, PermissionsRead = true, PermissionsEdit = true));
            }
            for (String f : readOnlyFields) {
                perms.add(new FieldPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    Field = sobjectName + '.' + f, PermissionsRead = true, PermissionsEdit = false));
            }
            insert perms;
            insert new PermissionSetAssignment(AssigneeId = u.Id, PermissionSetId = ps.Id);
        }
        return u;
    }
}
```

**`PartnerRenewalDiscountTest.cls`**
```apex
@IsTest
private class PartnerRenewalDiscountTest {
    @TestSetup
    static void setup() {
        insert new List<Account>{
            TestDataFactory.account('Partner Co', 'Partner', null),
            TestDataFactory.account('Customer Co', 'Customer', null)
        };
    }

    static Id accountId(String name) {
        return [SELECT Id FROM Account WHERE Name = :name LIMIT 1].Id;
    }

    // AC1 (positive): renewal on a Partner Account -> 10
    @IsTest
    static void partnerAccountRenewalGetsTenPercentDiscount() {
        Opportunity opp = TestDataFactory.renewalOpportunities(accountId('Partner Co'), 1)[0];
        Test.startTest();
        insert opp;                                 // fires the record-triggered flow
        Test.stopTest();
        Assert.areEqual(10, [SELECT Partner_Discount__c FROM Opportunity WHERE Id = :opp.Id].Partner_Discount__c,
            'Renewal on a Partner Account gets 10');
    }

    // AC2 (negative): renewal on a Customer Account stays blank
    @IsTest
    static void customerAccountRenewalDiscountStaysBlank() {
        Opportunity opp = TestDataFactory.renewalOpportunities(accountId('Customer Co'), 1)[0];
        Test.startTest();
        insert opp;
        Test.stopTest();
        Assert.isNull([SELECT Partner_Discount__c FROM Opportunity WHERE Id = :opp.Id].Partner_Discount__c,
            'Renewal on a Customer Account has no discount');
    }

    // AC3 (already set): seed 5 (differs from the 10 the flow writes) on a Customer Account, where the
    // create does not match; then move the Opportunity to the Partner Account, an edit that would match.
    @IsTest
    static void existingDiscountIsNotChangedOnEdit() {
        Opportunity opp = TestDataFactory.renewalOpportunities(accountId('Customer Co'), 1)[0];
        opp.Partner_Discount__c = 5;
        insert opp;
        Opportunity edited = new Opportunity(Id = opp.Id, AccountId = accountId('Partner Co'), Name = 'Edited renewal');
        Test.startTest();
        update edited;
        Test.stopTest();
        Assert.areEqual(5, [SELECT Partner_Discount__c FROM Opportunity WHERE Id = :opp.Id].Partner_Discount__c,
            'An existing Partner_Discount__c survives edits');
    }

    // Edge case: 200 renewals in one DML
    @IsTest
    static void bulkInsertOf200PartnerRenewalsAllGetDiscount() {
        List<Opportunity> rows = TestDataFactory.renewalOpportunities(accountId('Partner Co'), 200);
        Test.startTest();
        insert rows;
        Test.stopTest();
        Assert.areEqual(200, [SELECT COUNT() FROM Opportunity WHERE AccountId = :accountId('Partner Co')],
            'All 200 renewals were created');
        Assert.areEqual(200, [SELECT COUNT() FROM Opportunity
                              WHERE AccountId = :accountId('Partner Co') AND Partner_Discount__c = 10],
            'All 200 Partner renewals get 10');
    }

    // Edge case: user without edit access to Partner_Discount__c.
    // ASSUMES the logic is a record-triggered flow (system context), so the discount is still set.
    @IsTest
    static void userWithoutDiscountEditStillGetsTenPercent() {
        User u = RestrictedUser.create('Opportunity',
            new List<String>{ 'Name', 'StageName', 'CloseDate', 'AccountId', 'Type' },
            new List<String>{ 'Partner_Discount__c' });
        // The user must see the parent: make them its owner (non-setup DML, outside runAs).
        Account partner = TestDataFactory.account('Partner Owned', 'Partner', u.Id);
        insert partner;
        Opportunity opp = TestDataFactory.renewalOpportunities(partner.Id, 1)[0];

        System.runAs(u) {
            Assert.isFalse(Schema.SObjectType.Opportunity.fields.Partner_Discount__c.isUpdateable(),
                'Precondition: the user cannot edit Partner_Discount__c');
            Test.startTest();
            insert as user opp;
            Test.stopTest();
        }
        // Assert outside runAs, as the test's running user, so the assert can read the field.
        Assert.areEqual(10, [SELECT Partner_Discount__c FROM Opportunity WHERE Id = :opp.Id].Partner_Discount__c,
            'The flow sets the field the user cannot edit');
    }
}
```

## Run in the sandbox
Deploy only the new classes, not all of `force-app`:
```sh
sf project deploy start -o uat -m ApexClass:TestDataFactory -m ApexClass:RestrictedUser -m ApexClass:PartnerRenewalDiscountTest
sf apex run test -o uat --class-names PartnerRenewalDiscountTest --code-coverage --result-format json --wait 10 > test-result.json
```
In the JSON, read these:
- **Outcome:** `result.summary.outcome`, `passing` and `failing`.
- **Failures:** every `result.tests[]` entry whose `Outcome` isn't `Pass`, with its `Message` and `StackTrace`.
- **Coverage:** `result.coverage.coverage[]` `coveredPercent`.

Before handing over, run `sf apex run test -o uat --test-level RunLocalTests --code-coverage --result-format json --wait 30` once to catch anything this change broke elsewhere.
