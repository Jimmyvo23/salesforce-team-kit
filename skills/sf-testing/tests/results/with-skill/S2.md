# S2: Coverage push (with-skill)

I won't add tests without assertions just to push coverage over 75%: they pass even when the code is wrong. 75% is the floor Salesforce requires to deploy, not the goal, so these tests assert each behaviour of the class, and the coverage follows.

## Assumptions
- `OpportunityService` has one method, `openForAccounts(Set<Id>)`. It returns open Opportunities (`IsClosed = false`) for the given Accounts, and it runs `WITH USER_MODE`.
- Opportunity sharing is Private, and the sandbox has the `Minimum Access - Salesforce` profile.
- `IsClosed` can't be given FLS in the test. If the restricted-user test fails on field access, add it to the read-only list in `RestrictedUser`.
- `TestDataFactory` may already exist in `uat`. Retrieve it before deploying (`sf project retrieve start -o uat -m ApexClass:TestDataFactory`) and add the two methods below to it. Don't overwrite it. Neither it nor `RestrictedUser` is in the project.
- `sourceApiVersion` is 62.0, so new meta files use 62.0.

## Test plan

| # | Test method | Given | When | Then |
|---|---|---|---|---|
| 1 | `returnsOnlyOpenOppsOfRequestedAccount` | Target: 2 open and 2 closed Opps. Other: 1 open | `openForAccounts({Target})` | 2 results, all with Target's AccountId and an open stage |
| 2 | `accountWithOnlyClosedOppsReturnsEmpty` | Account with Closed Won and Closed Lost Opps | call | empty list |
| 3 | `multipleAccountsReturnUnionOfOpenOpps` | Target and Other | call with both | 3 results |
| 4 | `emptyIdSetReturnsEmptyList` | none | call with `new Set<Id>()` | empty list |
| 5 | `bulk200OpenOppsAllReturned` | 200 open Opps on one Account | call | 200 results |
| 6 | `userWithReadAccessSeesOwnOpenOpps` | restricted user owns the Account and an open Opp | call inside `runAs` | 1 result, the right Id |
| 7 | `userWithoutOpportunityAccessGetsQueryException` | user with no Opportunity permissions | call inside `runAs` | `QueryException` |

@IsTest
public class TestDataFactory {
    public static Account account(String name, Id ownerId) {
        Account a = new Account(Name = name);
        if (ownerId != null) { a.OwnerId = ownerId; }
        return a;                                  // caller inserts
    }

    public static Opportunity opportunity(Id accountId, String stageName, Id ownerId) {
        Opportunity o = new Opportunity(Name = 'ZZ_TEST Opp ' + stageName, AccountId = accountId,
            StageName = stageName, CloseDate = Date.today().addDays(30));
        if (ownerId != null) { o.OwnerId = ownerId; }
        return o;
    }

    public static List<Opportunity> opportunities(Id accountId, String stageName, Integer n) {
        List<Opportunity> rows = new List<Opportunity>();
        for (Integer i = 0; i < n; i++) {
            Opportunity o = opportunity(accountId, stageName, null);
            o.Name = 'ZZ_TEST Opp ' + stageName + ' ' + i;
            rows.add(o);
        }
        return rows;
    }

    /** Minimum Access user with no permission set. The insert is setup DML, so it runs inside runAs. */
    public static User minimumAccessUser() {
        Profile p = [SELECT Id FROM Profile WHERE Name = 'Minimum Access - Salesforce' LIMIT 1];
        String unique = String.valueOf(Crypto.getRandomLong()).remove('-');
        User u = new User(Alias = 'noacc', LastName = 'NoAccess', Email = 'noacc' + unique + '@example.com',
            Username = 'noacc' + unique + '@example.com.test', ProfileId = p.Id,
            EmailEncodingKey = 'UTF-8', LanguageLocaleKey = 'en_US', LocaleSidKey = 'en_US',
            TimeZoneSidKey = 'America/Los_Angeles');
        System.runAs(new User(Id = UserInfo.getUserId())) { insert u; }
        return u;
    }
}

@IsTest
public class RestrictedUser {
    /** A Minimum Access user with Read/Create on the object, Edit on editFields, Read-only on readOnlyFields. */
    public static User create(String sobjectName, List<String> editFields, List<String> readOnlyFields) {
        Profile p = [SELECT Id FROM Profile WHERE Name = 'Minimum Access - Salesforce' LIMIT 1];
        String unique = String.valueOf(Crypto.getRandomLong()).remove('-');
        User u = new User(Alias = 'rtest', LastName = 'Restricted', Email = 'rtest' + unique + '@example.com',
            Username = 'rtest' + unique + '@example.com.test', ProfileId = p.Id,
            EmailEncodingKey = 'UTF-8', LanguageLocaleKey = 'en_US', LocaleSidKey = 'en_US',
            TimeZoneSidKey = 'America/Los_Angeles');
        System.runAs(new User(Id = UserInfo.getUserId())) {
            insert u;
            PermissionSet ps = new PermissionSet(Name = 'Test_Restricted_' + unique.left(10), Label = 'Test restricted');
            insert ps;
            List<SObject> perms = new List<SObject>{
                new ObjectPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    PermissionsRead = true, PermissionsCreate = true, PermissionsEdit = true),
                new ObjectPermissions(ParentId = ps.Id, SobjectType = 'Account', PermissionsRead = true)
            };
            Map<String, Schema.SObjectField> fieldMap =
                Schema.getGlobalDescribe().get(sobjectName).getDescribe().fields.getMap();
            for (String f : editFields) {
                if (!fieldMap.get(f).getDescribe().isPermissionable()) { continue; }
                perms.add(new FieldPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    Field = sobjectName + '.' + f, PermissionsRead = true, PermissionsEdit = true));
            }
            for (String f : readOnlyFields) {
                if (!fieldMap.get(f).getDescribe().isPermissionable()) { continue; }
                perms.add(new FieldPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    Field = sobjectName + '.' + f, PermissionsRead = true, PermissionsEdit = false));
            }
            insert perms;
            insert new PermissionSetAssignment(AssigneeId = u.Id, PermissionSetId = ps.Id);
        }
        return u;
    }
}

`force-app/main/default/classes/OpportunityServiceTest.cls`:
```apex
@IsTest
private class OpportunityServiceTest {
    @TestSetup
    static void setup() {
        List<Account> accounts = new List<Account>{
            TestDataFactory.account('Target', null),
            TestDataFactory.account('Other', null),
            TestDataFactory.account('ClosedOnly', null)
        };
        insert accounts;
        Id target = accounts[0].Id;
        Id other = accounts[1].Id;
        Id closedOnly = accounts[2].Id;
        insert new List<Opportunity>{
            TestDataFactory.opportunity(target, 'Prospecting', null),
            TestDataFactory.opportunity(target, 'Qualification', null),
            TestDataFactory.opportunity(target, 'Closed Won', null),
            TestDataFactory.opportunity(target, 'Closed Lost', null),
            TestDataFactory.opportunity(other, 'Prospecting', null),
            TestDataFactory.opportunity(closedOnly, 'Closed Won', null),
            TestDataFactory.opportunity(closedOnly, 'Closed Lost', null)
        };
    }

    static Id accountId(String name) {
        return [SELECT Id FROM Account WHERE Name = :name LIMIT 1].Id;
    }

    @IsTest
    static void returnsOnlyOpenOppsOfRequestedAccount() {
        Id target = accountId('Target');
        Test.startTest();
        List<Opportunity> result = OpportunityService.openForAccounts(new Set<Id>{ target });
        Test.stopTest();
        Assert.areEqual(2, result.size(), 'Only the 2 open Opps of Target');
        Set<String> stages = new Set<String>();
        for (Opportunity o : result) { stages.add(o.StageName); }
        Assert.areEqual(new Set<String>{ 'Prospecting', 'Qualification' }, stages, 'Open stages only');
        Assert.areEqual(2, [SELECT COUNT() FROM Opportunity WHERE Id IN :result AND AccountId = :target],
            'All results belong to Target');
    }

    @IsTest
    static void accountWithOnlyClosedOppsReturnsEmpty() {
        Id closedOnly = accountId('ClosedOnly');
        Test.startTest();
        List<Opportunity> result = OpportunityService.openForAccounts(new Set<Id>{ closedOnly });
        Test.stopTest();
        Assert.isTrue(result.isEmpty(), 'Closed Won and Closed Lost are excluded');
    }

    @IsTest
    static void multipleAccountsReturnUnionOfOpenOpps() {
        Test.startTest();
        List<Opportunity> result = OpportunityService.openForAccounts(
            new Set<Id>{ accountId('Target'), accountId('Other') });
        Test.stopTest();
        Assert.areEqual(3, result.size(), '2 open on Target + 1 open on Other');
    }

    @IsTest
    static void emptyIdSetReturnsEmptyList() {
        Test.startTest();
        List<Opportunity> result = OpportunityService.openForAccounts(new Set<Id>());
        Test.stopTest();
        Assert.isTrue(result.isEmpty(), 'Empty input, empty result');
    }

    @IsTest
    static void bulk200OpenOppsAllReturned() {
        Account bulk = TestDataFactory.account('Bulk', null);
        insert bulk;
        insert TestDataFactory.opportunities(bulk.Id, 'Prospecting', 200);
        Test.startTest();
        List<Opportunity> result = OpportunityService.openForAccounts(new Set<Id>{ bulk.Id });
        Test.stopTest();
        Assert.areEqual(200, result.size(), 'All 200 open Opps returned');
    }

    @IsTest
    static void userWithReadAccessSeesOwnOpenOpps() {
        User u = RestrictedUser.create('Opportunity',
            new List<String>{ 'Name', 'StageName', 'CloseDate', 'AccountId' }, new List<String>());
        Account acc = TestDataFactory.account('Owned', u.Id);
        insert acc;
        Opportunity opp = TestDataFactory.opportunity(acc.Id, 'Prospecting', u.Id);
        insert opp;
        List<Opportunity> result;
        System.runAs(u) {
            Assert.isTrue(Schema.SObjectType.Opportunity.isAccessible(), 'Precondition: user can read Opportunity');
            Test.startTest();
            result = OpportunityService.openForAccounts(new Set<Id>{ acc.Id });
            Test.stopTest();
        }
        Assert.areEqual(1, result.size(), 'The user sees their own open Opp');
        Assert.areEqual(opp.Id, result[0].Id, 'It is the Opp they own');
    }

    @IsTest
    static void userWithoutOpportunityAccessGetsQueryException() {
        User u = TestDataFactory.minimumAccessUser();
        Id target = accountId('Target');
        System.runAs(u) {
            Assert.isFalse(Schema.SObjectType.Opportunity.isAccessible(),
                'Precondition: the user cannot read Opportunity');
            Test.startTest();
            try {
                OpportunityService.openForAccounts(new Set<Id>{ target });
                Assert.fail('Expected QueryException: WITH USER_MODE enforces object access');
            } catch (QueryException e) {
                Assert.isTrue(e.getMessage().contains('Opportunity'), 'The error names the object');
            }
            Test.stopTest();
        }
    }
}
```

## Run in the sandbox

Deploy only the new classes, not all of `force-app`:
```sh
sf project deploy start -o uat -m ApexClass:OpportunityServiceTest -m ApexClass:RestrictedUser -m ApexClass:TestDataFactory
sf apex run test -o uat --class-names OpportunityServiceTest --code-coverage --result-format json --wait 10 > test-result.json
```
Read these in `test-result.json`:
- `result.summary.outcome` should be `Passed`, with `failing` at 0.
- Any `result.tests[]` entry whose `Outcome` isn't `Pass`: read its `Message` and `StackTrace`.
- `result.coverage.coverage[]`: `coveredPercent` for `OpportunityService`. The `lines` map should have no `0` values.

Then run `sf apex run test -o uat --test-level RunLocalTests --result-format json --wait 20` once, to check the org-wide number and that nothing else broke. Production re-runs tests on its own data, so its number can differ from the sandbox's. A person deploys to production with change sets.
