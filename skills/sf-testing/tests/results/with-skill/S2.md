# S2: Coverage push (with-skill)

## Coverage is a floor

I won't add tests without assertions just to push coverage over 75%: they pass even when the code is wrong. 75% is the floor Salesforce requires to deploy, not the goal, so these tests assert each behaviour of the class, and the coverage follows.

**Not run yet:** I haven't run anything against `uat`. Run the command at the end and paste the output.

## Assumptions
- `OpportunityService` has one method, `openForAccounts(Set<Id>)`. Its only query has `WITH USER_MODE` set explicitly, so the CRUD/FLS check applies at API 62.0 too.
- The project has no `TestDataFactory`. I'm adding one, but `uat` may already have a class with that name. If so, retrieve it (`sf project retrieve start -o uat -m ApexClass:TestDataFactory`) and add the two methods below instead of replacing it.
- The restricted-user test uses the `RestrictedUser` helper from the skill's `references/apex-tests.md`. It isn't in the project, so save it too. It needs a **Minimum Access - Salesforce** profile in `uat`.
- `IsClosed` is a formula field the user needs Read on. I assume the permission set grants it. If the allowed-user test fails on field access, that's the reason.
- I haven't read the uncovered lines from a coverage JSON. This class is a single query, so the 32% gap is most likely that line never running with data.

## Test plan

| # | Test method | Given | When | Then |
|---|---|---|---|---|
| 1 | `returnsOnlyOpenOpportunitiesOfRequestedAccounts` (positive) | Target: 2 open and 1 closed Opp. Other: 1 open Opp | `openForAccounts({Target})` | 2 results, both with Target's `AccountId`, none closed |
| 2 | `accountWithOnlyClosedOpportunitiesReturnsEmpty` (negative) | Account with only a Closed Won Opp | Call it | Empty list |
| 3 | `emptyAccountSetReturnsEmpty` (negative) | None | Pass an empty set | Empty list |
| 4 | `bulk200OpenOpportunitiesAllReturned` (bulk) | 200 open Opps on one Account, 1 closed | Call it | 200 results, every one open and on that Account |
| 5 | `userWithOpportunityReadSeesTheirOpenOpportunities` (restricted user) | User with Opportunity access who owns the Account and Opps | `runAs` the user, call it | 1 open Opp returned |
| 6 | `userWithoutOpportunityAccessGetsQueryException` (restricted user) | User with no Opportunity permission | `runAs` the user, call it | `QueryException`, asserted by type and message |

```apex
@IsTest
public class RestrictedUser {
    /** A Minimum Access user with Read/Create on the object, Edit on editFields, Read-only on readOnlyFields. */
    public static User create(String sobjectName, List<String> editFields, List<String> readOnlyFields) {
        Profile p = [SELECT Id FROM Profile WHERE Name = 'Minimum Access - Salesforce' LIMIT 1];
        String unique = String.valueOf(Crypto.getRandomLong()).remove('-');   // usernames are unique across all orgs
        User u = new User(Alias = 'rtest', LastName = 'Restricted', Email = 'rtest' + unique + '@example.com',
            Username = 'rtest' + unique + '@example.com.test', ProfileId = p.Id,
            EmailEncodingKey = 'UTF-8', LanguageLocaleKey = 'en_US', LocaleSidKey = 'en_US',
            TimeZoneSidKey = 'America/Los_Angeles');
        System.runAs(new User(Id = UserInfo.getUserId())) {
            insert u;
            PermissionSet ps = new PermissionSet(Name = 'Test_Restricted_' + unique.left(10), Label = 'Test restricted');
            insert ps;
            List<SObject> perms = new List<SObject>{
                new ObjectPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    PermissionsRead = true, PermissionsCreate = true, PermissionsEdit = true),
                new ObjectPermissions(ParentId = ps.Id, SobjectType = 'Account', PermissionsRead = true)
            };
            Map<String, Schema.SObjectField> fieldMap =
                Schema.getGlobalDescribe().get(sobjectName).getDescribe().fields.getMap();
            for (String f : editFields) {
                if (!fieldMap.get(f).getDescribe().isPermissionable()) { continue; }   // e.g. OwnerId, master-detail
                perms.add(new FieldPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    Field = sobjectName + '.' + f, PermissionsRead = true, PermissionsEdit = true));
            }
            for (String f : readOnlyFields) {
                perms.add(new FieldPermissions(ParentId = ps.Id, SobjectType = sobjectName,
                    Field = sobjectName + '.' + f, PermissionsRead = true, PermissionsEdit = false));
            }
            insert perms;
            insert new PermissionSetAssignment(AssigneeId = u.Id, PermissionSetId = ps.Id);
        }
        return u;
    }
}
```

`force-app/main/default/classes/OpportunityServiceTest.cls`
```apex
@IsTest
private class OpportunityServiceTest {
    @TestSetup
    static void setup() {
        List<Account> accounts = new List<Account>{
            TestDataFactory.account('Target', null),
            TestDataFactory.account('Other', null),
            TestDataFactory.account('Only Closed', null),
            TestDataFactory.account('Bulk', null)
        };
        insert accounts;
        Map<String, Id> ids = new Map<String, Id>();
        for (Account a : accounts) { ids.put(a.Name, a.Id); }

        List<Opportunity> opps = new List<Opportunity>();
        opps.addAll(TestDataFactory.opportunities(ids.get('Target'), 'Prospecting', 2));
        opps.addAll(TestDataFactory.opportunities(ids.get('Target'), 'Closed Won', 1));
        opps.addAll(TestDataFactory.opportunities(ids.get('Other'), 'Prospecting', 1));
        opps.addAll(TestDataFactory.opportunities(ids.get('Only Closed'), 'Closed Won', 1));
        opps.addAll(TestDataFactory.opportunities(ids.get('Bulk'), 'Qualification', 200));
        opps.addAll(TestDataFactory.opportunities(ids.get('Bulk'), 'Closed Lost', 1));
        insert opps;
    }

    static Id accountId(String name) {
        return [SELECT Id FROM Account WHERE Name = :name LIMIT 1].Id;
    }

    // Positive: only open Opps of the requested Accounts
    @IsTest
    static void returnsOnlyOpenOpportunitiesOfRequestedAccounts() {
        Id targetId = accountId('Target');
        Test.startTest();
        List<Opportunity> result = OpportunityService.openForAccounts(new Set<Id>{ targetId });
        Test.stopTest();
        Assert.areEqual(2, result.size(), 'Only the 2 open Opps of Target');
        for (Opportunity o : result) {
            Assert.areEqual('Prospecting', o.StageName, 'Open stage returned');
            Assert.areNotEqual('Closed Won', o.StageName, 'No closed Opps');
        }
        Assert.areEqual(2, [SELECT COUNT() FROM Opportunity WHERE Id IN :result AND AccountId = :targetId],
            'Every result belongs to Target, none to Other');
    }

    // Negative: closed-only Account
    @IsTest
    static void accountWithOnlyClosedOpportunitiesReturnsEmpty() {
        Id closedId = accountId('Only Closed');
        Test.startTest();
        List<Opportunity> result = OpportunityService.openForAccounts(new Set<Id>{ closedId });
        Test.stopTest();
        Assert.isTrue(result.isEmpty(), 'Closed Opps are never returned');
    }

    // Negative: empty input
    @IsTest
    static void emptyAccountSetReturnsEmpty() {
        Test.startTest();
        List<Opportunity> result = OpportunityService.openForAccounts(new Set<Id>());
        Test.stopTest();
        Assert.isTrue(result.isEmpty(), 'Empty input, empty result');
    }

    // Bulk: 200 open Opps (plus 1 closed) on one Account
    @IsTest
    static void bulk200OpenOpportunitiesAllReturned() {
        Id bulkId = accountId('Bulk');
        Test.startTest();
        List<Opportunity> result = OpportunityService.openForAccounts(new Set<Id>{ bulkId });
        Test.stopTest();
        Assert.areEqual(200, result.size(), 'All 200 open Opps, not the closed one');
        for (Opportunity o : result) {
            Assert.areEqual('Qualification', o.StageName, 'Every result is an open Opp');
        }
    }

    // Restricted user WITH access: user-mode query returns the user's open Opps
    @IsTest
    static void userWithOpportunityReadSeesTheirOpenOpportunities() {
        User u = RestrictedUser.create('Opportunity',
            new List<String>{ 'Name', 'StageName', 'CloseDate', 'AccountId' }, new List<String>());
        Account owned = TestDataFactory.account('Owned By Restricted', u.Id);
        insert owned;
        List<Opportunity> opps = TestDataFactory.opportunities(owned.Id, 'Prospecting', 1);
        opps.addAll(TestDataFactory.opportunities(owned.Id, 'Closed Won', 1));
        for (Opportunity o : opps) { o.OwnerId = u.Id; }
        insert opps;

        List<Opportunity> result;
        System.runAs(u) {
            Assert.isTrue(Schema.SObjectType.Opportunity.isAccessible(), 'Precondition: user can read Opportunity');
            Test.startTest();
            result = OpportunityService.openForAccounts(new Set<Id>{ owned.Id });
            Test.stopTest();
        }
        Assert.areEqual(1, result.size(), 'The user sees only the open Opp');
        Assert.areEqual('Prospecting', result[0].StageName, 'Open stage returned');
    }

    // Restricted user WITHOUT access: WITH USER_MODE makes the query throw.
    // Assumption: the story wants the exception, not an empty list.
    @IsTest
    static void userWithoutOpportunityAccessGetsQueryException() {
        // Helper grants Case + Account read only: no Opportunity permission at all
        User u = RestrictedUser.create('Case', new List<String>{ 'Subject' }, new List<String>());
        Id targetId = accountId('Target');

        System.runAs(u) {
            Assert.isFalse(Schema.SObjectType.Opportunity.isAccessible(),
                'Precondition: the user cannot read Opportunity');
            Test.startTest();
            try {
                OpportunityService.openForAccounts(new Set<Id>{ targetId });
                Assert.fail('Expected QueryException: no Opportunity access in user mode');
            } catch (QueryException e) {
                Assert.isTrue(e.getMessage().contains('Opportunity'), 'The error names the object: ' + e.getMessage());
            }
            Test.stopTest();
        }
    }
}
```

## Run it (sandbox `uat`)

```sh
sf project deploy start -o uat -m ApexClass:TestDataFactory -m ApexClass:RestrictedUser -m ApexClass:OpportunityServiceTest
sf apex run test -o uat --class-names OpportunityServiceTest --code-coverage --result-format json --wait 10 > test-result.json
```

Read these fields in the JSON:
- `result.summary.outcome`, `passing` and `failing`.
- Every `result.tests[]` entry whose `Outcome` isn't `Pass`, with its `Message` and `StackTrace`.
- `result.coverage.coverage[]`, the `coveredPercent` for `OpportunityService`. Every line should be covered, so it should reach 100%.

Before handing over, run `sf apex run test -o uat --test-level RunLocalTests --code-coverage --result-format json --wait 30`. Check `orgWideCoverage` there as well, because deployment needs 75% across the whole org, not just this class. Deploying to production is a change-set job for a person, so I've left it out.
