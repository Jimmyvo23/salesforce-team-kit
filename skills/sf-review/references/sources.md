# Sources

On 2026-10-19, developer.salesforce.com returned HTTP 403 to WebFetch and curl, and help.salesforce.com renders only with JavaScript. The Apex Developer Guide (Version 68.0, Winter '27) was read from its official PDF edition. Code Analyzer flags come from the CLI's own help (`sf code-analyzer run --help`, plugin `code-analyzer` 5.14.0, read without connecting to any org); severity numbers come from the Code Analyzer source and search excerpts of the Code Analyzer guide. Detailed security, testing, flow and Apex rules are sourced in the sibling skills (sf-security, sf-testing, sf-flow, sf-apex), which this skill points to.

- Review checklist (CRUD/FLS and `USER_MODE`, sharing keywords): https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/salesforce_apex_developer_guide.pdf ("Use the with sharing, without sharing, and inherited sharing Keywords", PDF p.93) and the sf-security / sf-apex sources (checked 2026-10-19)
- SOQL or DML in loops, hard-coded Ids, test asserts (PMD rule names `OperationWithLimitsInLoop`, `AvoidHardcodingId`, `ApexCRUDViolation`, `ApexSharingViolations`, `ApexSOQLInjection`, `ApexUnitTestClassShouldHaveAsserts`): https://pmd.github.io/pmd/pmd_rules_apex.html (checked 2026-10-19)
- Automation overlap, which automation wins (before-save flows step 3, before triggers step 4, after triggers step 8): https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/salesforce_apex_developer_guide.pdf ("Triggers and Order of Execution", PDF p.285) (checked 2026-10-19)
- Running `sf code-analyzer run` (`--target`, `--workspace`, `--rule-selector`, `--severity-threshold`, `--view`, `--output-file`, `--config-file`, `--no-suppressions`; `sf code-analyzer rules`): `sf code-analyzer run --help` and https://developer.salesforce.com/docs/platform/salesforce-cli-reference/guide/cli_reference_code-analyzer_run.html (checked 2026-10-19)
- Severity thresholds (v5: 1 Critical, 2 High, 3 Moderate, 4 Low, 5 Info; retired scanner: 1 high, 2 moderate, 3 low): https://github.com/forcedotcom/code-analyzer-core/blob/main/packages/code-analyzer-engine-api/src/rules.ts (`SeverityLevel`) and https://developer.salesforce.com/docs/platform/salesforce-code-analyzer/guide/code-analyzer-3x.html (checked 2026-10-19)
- Reading results (`violationCounts` with `sev1`…`sev5`, `violations`): https://developer.salesforce.com/docs/platform/salesforce-code-analyzer/guide/output-schemas-json.html (checked 2026-10-19)
- Verdict format and handoff targets: the kit's `agents/reviewer.md` and `templates/team.json` (checked 2026-10-19)
