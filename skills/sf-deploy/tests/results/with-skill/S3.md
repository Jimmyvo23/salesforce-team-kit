# Change set checklist: T-012

Task: T-012 | Source sandbox: `uat` | Prepared for: Jimmy | Date: 2026-10-19

## 1. Summary
Opportunities get a new field, Partner Discount (`Partner_Discount__c`). The Renewal_Discount flow and the PartnerDiscountService Apex class use it to apply partner discounts on renewals. Users with the Partner_Manager permission set can see and edit the field. This touches the Opportunity object.

## 2. Components to add
The order is dependency order: each component comes after what it refers to.

| # | Type | Name | Notes |
|---|---|---|---|
| 1 | Custom field | `Opportunity.Partner_Discount__c` | Field first: the class, the flow and the permission set all refer to it. |
| 2 | Permission set | `Partner_Manager` | Grants field-level security on the new field. Its field permissions only travel because the field is in this change set. |
| 3 | Apex class | `PartnerDiscountService` | Refers to the field. |
| 4 | Apex class (test) | `PartnerDiscountServiceTest` | Provides coverage for #3. |
| 5 | Flow | `Renewal_Discount` | Add the version that passed UAT. Refers to the field and possibly to the class. |

**Commonly missed items**
- **Field-level security:** `Partner_Manager` grants Read/Edit on `Opportunity.Partner_Discount__c` (row 2). Confirm in UAT that the permission set has the `fieldPermissions` entry.
- **Record types and layouts:** Not needed unless the field is on a layout. If the review put it on an Opportunity layout, add that layout as row 6 and confirm the profile layout assignments.
- **Custom metadata records:** Not needed, unless the class or flow reads a custom metadata type. If so, add its records too.
- **Flow version:** Add the `Renewal_Discount` version that passed UAT. Confirm the version number before building the change set. Activation is in section 5.
- **Lightning page activations:** Not needed, unless a page was changed for this task.
- **Custom labels and custom settings:** Not needed, unless `PartnerDiscountService` uses a label or setting. If it does, add it before the class.

## 4. Deployment settings
- Test level: **Run specified tests**
- Tests to run: `PartnerDiscountServiceTest`
- `PartnerDiscountService` needs at least 75% coverage from that test.

## 5. After deploying
1. Setup > Flows > `Renewal_Discount` > the version from the change set > **Activate**. Change sets deploy flows inactive unless "Deploy processes and flows as active" is on in production.
2. Setup > Permission Sets > `Partner_Manager` > Manage Assignments: assign it to the Partner Manager users. Confirm the user list with the requester.

## 6. Rollback
- **Flow:** Deactivate `Renewal_Discount`, or activate its previous version.
- **Permission set:** Remove the new assignments, or remove the `Partner_Discount__c` field permission.
- **Apex:** Apex can't be edited in production. Turn off the flow that calls it, or deploy the previous version in a change set from a sandbox that still has it.
- **Field:** Leave it in place, because deleting it deletes its data. Remove its field-level security and take it off any layouts.
- **Data loaded:** None.
